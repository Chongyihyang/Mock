# List reference
`List.of(...)`, `List.copyOf(collection)`, `get(index)`, `size()`, `isEmpty()`, `contains(value)`, `stream()`.
`List.of` and `List.copyOf` produce unmodifiable lists. `new ArrayList<>(collection)` copies into a mutable list.
`List<T>` is invariant; `List<Subtype>` is not a `List<Supertype>`.
